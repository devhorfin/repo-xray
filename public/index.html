CHECKS.TXT

1 · Clock

The first commit's date against the day the repository and the account were created, and whether the author and committer clocks agree.

2 · Metronome

Commits per year and the gap between commits. Real work is lumpy. A fixed beat for years is a schedule.

3 · Names

Every author's name against the address they commit with. An address that reads like someone else's full name is a costume more often than a quirk.

4 · Masks

GitHub's no-reply addresses carry the user's numeric id. If the owner's id commits under another name, that's one person in several coats.

5 · Crowd

Forks, stars and pull requests that arrive within hours of each other from name-plus-digits accounts.

6 · Claims

The README against the code: money that "moves" with no transfer, Anchor's placeholder program id, "implemented" next to "not implemented", an audit nobody can find.

Grade

Two flags, or one flag and two notes, is DRESSED UP. One flag or two notes is LOOK CLOSER. Otherwise CLEAN, which is not proof of anything else.

An old project moved from elsewhere can earn a note; it takes several checks together to earn a flag. The checks read public data and can't tell who typed a commit. Unknown is not fake.

Pay per call

An agent asks, gets a 402 with the price, pays in USDC over x402, and the same card comes back as JSON with a receipt. No key, no account. On Solana the payment is final in about 150 ms since Alpenglow, so the money doesn't hold up the answer.
