REPO X-RAY v0.3.0
Five checks on a repository's history

Everyone checks the stars. Nobody checks the clock.

Paste a GitHub link. Ten seconds later you get the clock, the rhythm, the names, the masks and the crowd, each with the line of evidence it rests on. No verdict without a receipt.

Try or . Public repositories only; nothing is written to GitHub.

01 — What each check reads
1

Clock

The first commit's date against the day the repository and the account were created, and whether the author and committer clocks agree.

2

Metronome

Commits per year and the gap between commits. Real work is lumpy. A fixed beat for years is a schedule.

3

Names

Every author's name against the address they commit with. A name that shares nothing with its email is a costume more often than a quirk.

4

Masks

GitHub's own no-reply addresses carry the user's numeric id. If the owner's id commits under another name, that's one person in several coats.

5

Crowd

Forks, stars and pull requests that arrive within minutes of each other from name-plus-digits accounts.

6

Claims

What the README promises against what the code holds: money that "moves" with no transfer in the program, a program id that is Anchor's placeholder or sits on no network, "implemented" next to "not implemented", an audit nobody can find, a partner the code never names.

=

Grade

CLEAN, LOOK CLOSER or DRESSED UP. Two flags, or one flag with two notes, is DRESSED UP. An old project moved from elsewhere can earn a note; it takes several checks together to earn a flag. Under the checks: the tokens on DexScreener that carry the repository's name.

No key, no account. Your agent asks, gets a 402 with the price, pays, and the card comes back as JSON. On Solana the payment is final in about 150 ms since Alpenglow, so the answer is not held up by the money.
